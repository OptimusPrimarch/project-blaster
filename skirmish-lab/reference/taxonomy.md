# Mechanic Taxonomy (M01-M20)

The backbone for comparing games. Every game card has one section per ID, in this order. If a game has no rule for a mechanic, the card says `NOT SPECIFIED`. If a game has a mechanic that fits nowhere, record it under "Distinctive ideas" and propose a new ID here.

| ID | Mechanic | What to capture |
|---|---|---|
| M01 | Game structure & victory | Rounds/turns, game length, how a game ends, how a winner is decided |
| M02 | Setup & deployment | Table size, terrain placement, deployment zones, who deploys first, hidden deployment |
| M03 | Activation & turn order | Alternating, I-go-you-go, cards/tokens/dice-driven, initiative, can a player run out of activations |
| M04 | Action economy | Action points vs fixed actions, what a model can do per activation, action limits |
| M05 | Core resolution | Dice type and count, target numbers, pools vs single roll, opposed vs unopposed, modifiers, crits/fumbles |
| M06 | Movement | Measuring, speed, terrain cost, climbing/jumping, facing, engagement/zone of control |
| M07 | Ranged combat | Targeting, range bands, to-hit, cover effects, rate of fire, friendly fire |
| M08 | Melee combat | Charging, engagement, resolution (single roll vs exchange), support bonuses, disengaging |
| M09 | Damage, armor & wounds | Armor/save model, wound tracks, injuries, death, recovery, stun/status effects |
| M10 | Reactions & interrupts | Overwatch, counter-actions, out-of-turn play, how reactions are paid for |
| M11 | Terrain, cover & line of sight | LOS method, cover types, vertical play, hazards, destructible terrain |
| M12 | Morale, command & leadership | Morale/fear tests, leaders, cohesion, orders, activation difficulty |
| M13 | Luck management | Rerolls, tokens, fate points, "hero" mitigation, dice vs deterministic elements |
| M14 | Model profiles & stat scale | Stat lines, scale of numbers, classes/archetypes, how much stats matter |
| M15 | Weapons & equipment | Weapon traits, loadout rules, upgrades, grenades/gadgets, consumables |
| M16 | Special rules, traits & abilities | Keyword systems, skills, psychic/magic/tech powers, how they are tracked |
| M17 | Force building | Points/roster/cards, army composition limits, faction structure |
| M18 | Scenarios & objectives | Mission types, objective mechanics, scoring, asymmetry |
| M19 | Campaign & progression | Between-game advancement, injuries, resources, narrative hooks (may be absent) |
| M20 | Play feel | Complexity, bookkeeping/tokens, typical play time, learning curve, downtime between turns (as the text states or implies; my own feel goes in `preferences/`) |

## Adding or changing an ID
1. Propose it to me first. 2. Add it here with a date in the change log. 3. Update existing game cards (a short `NOT SPECIFIED` stub is fine until revisited).
