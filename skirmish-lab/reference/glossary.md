# Glossary (canonical terms)

Games name the same idea differently. Use the **Canonical** term in game cards, comparisons, and the design; keep the book's own term in parentheses on first use, e.g. "activation (impulse)".

| Canonical | Meaning | Common aliases in rulebooks |
|---|---|---|
| Round | One full cycle in which every model/unit can act | Turn, game turn, battle round |
| Activation | One model or unit's chance to act | Turn, impulse, order, action phase |
| Action | One thing a model does during an activation | Order, option, command |
| Action point (AP) | Currency spent on actions | AP, actions, orders, command points |
| Model | One individual miniature | Figure, character, trooper, operative |
| Unit | A group of models that act together | Squad, fireteam, team, crew |
| Leader | Model with command or special status | Captain, sergeant, commander |
| Test | A dice roll to see if something succeeds | Check, roll, save, challenge |
| Target number | Value a roll must meet or beat | TN, difficulty, to-hit, quality |
| Modifier | A bonus/penalty applied to a roll or stat | Bonus, penalty, DM, +/- |
| Dice pool | Roll several dice and count successes | Success counting |
| Critical | Exceptionally good roll with extra effect | Crit, natural max, exploding |
| Wound | Unit of damage a model can take | Hit point, health, wound box |
| Armor | Reduction or avoidance of damage | Save, defense, toughness, protection |
| Down / out of action | Model removed or incapacitated | Casualty, KO, taken out, dead |
| Morale | Willingness of models/forces to keep fighting | Nerve, courage, leadership test, bottle test |
| Cover | Terrain benefit when shot at | Concealment, obscured, protection |
| Line of sight (LOS) | Whether one model can see another | LoS, visibility, true LOS |
| Engaged | Models in melee range of each other | Locked in combat, in contact, zone of control |
| Overwatch | Holding fire to react to enemy movement | Reaction fire, suppressive, interrupt |
| Reaction | Out-of-turn response | Interrupt, counter, opportunity action |
| Objective | A marker or place that scores points or wins | Mission marker, point of interest |
| Deployment zone | Where models start | Setup zone, drop zone |
| Keyword / trait | Short label that adds rules to a weapon or model | Special rule, tag, ability, skill |
| Faction | A force's overall type/side | Army, warband, crew, tribe |

## Adding terms
Add a row whenever a game card or comparison needs a new canonical term. Record aliases as you meet them in each book; that is how cross-game comparison stays honest.
