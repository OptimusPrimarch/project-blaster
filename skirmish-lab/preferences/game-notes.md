# Per-Game Notes (my opinions, in my words)

Captured **before** Claude reads the books, so the books don't shape my opinions. Claude records these but never edits or "improves" them. Dated entries only; if I change my mind, add a new line.

## How this file works
- **Tier 1 (now):** gut-level notes per game, using the block below. About 2 minutes per game. Specific beats broad: "reactions cost an activation, so using them is a real choice" is far more useful than "good combat".
- **Tier 2 (after a game's card exists):** per-mechanic ratings keyed to `reference/taxonomy.md` (M01-M20), done as an interview guided by the card. Ratings: Love / Like / Meh / Dislike / Hate, plus a short why. Results go in a `Tier 2` section under that game.

## Example (fictional; delete when real entries exist)
### example-game (Example Game, 1st ed.)
- Familiarity: regular (~20 games)
- Verdict: great tension, too much paperwork
- Love: reaction fire costs your next action, so it's a real choice; short rules that fit on a card
- Hate: every model tracks four separate status markers
- Activation style: alternating
- Anything else: would play again with the bookkeeping stripped out
